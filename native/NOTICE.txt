OmniMorph acceleration native library

The ABI, validation, scalar, SSE2, AVX2 and NEON kernels in this directory are
independently implemented for OmniMorph. No source file from openysm.cpp or
Sparkle-Morpher has been copied into this native library.

Reference projects (algorithm/architecture comparison only):
openysm.cpp: https://github.com/OpenYSMDev/openysm.cpp
Sparkle-Morpher: https://github.com/sdf123098/Sparkle-Morpher

Windows builds link the MSVC C/C++ runtime statically. Linux builds dynamically
link system glibc, libstdc++ and libgcc_s; macOS builds dynamically link system
libc++ and libSystem. These system libraries are not copied into this JAR.
Android arm64-v8a builds use NDK r28c and statically link its C++ runtime.
The NDK notices are included under natives/android-aarch64/licenses/.
GCC runtime licensing: https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html
LLVM libc++ licensing: https://github.com/llvm/llvm-project/blob/main/libcxx/LICENSE.TXT
Operating-system dependencies are recorded from the actual build in the platform manifest.
The project license applies to these independently written sources.
