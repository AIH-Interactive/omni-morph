## 客户端检查点

- 衣柜刷新离开本地预览来源，主动查询当前玩家 UUID；连接可用时复用认证，避免清空后再重新认证的窗口。
  新资料/模型完成前保留可见模型，503 等失败不把保留的本地预览标成已上传。
- 未注册 UUID 的 404 表示无云端装备，清除旧云端选择和进度，不弹“未找到用户”错误。
- 保持 Figura 的 `玩家 UUID → equipped → 资源 owner/id/hash → 缓存或下载 → 玩家 Avatar` 匹配链，
  不依赖玩家名字、文件名或模型显示名称。Figura Cloud 返回的资料 UUID 若存在，必须与请求 UUID 一致。
  对照 [Figura UserData](https://github.com/FiguraMC/Figura/blob/1.20/common/src/main/java/org/figuramc/figura/avatar/UserData.java)
  与 [NetworkStuff](https://github.com/FiguraMC/Figura/blob/1.20/common/src/main/java/org/figuramc/figura/backend2/NetworkStuff.java)。
- 衣柜预览底部新增上传进度条，中英文阶段包括准备、发送、等待装备确认；发送百分比来自实际 HTTP 请求体字节，
  不定阶段不编造百分比。Figura Cloud 与 Protobuf 共用传输计数；进度不按模型引擎分叉。
- 上传期间禁止重复手动上传和删除；失败、选模、断连及成功完成清理进度，旧回调不能关闭新上传进度。
  点击上传不再提前丢弃本地来源。
