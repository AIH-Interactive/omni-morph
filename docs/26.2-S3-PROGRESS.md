## 已核实的原版契约

- 通过 minecraft-dev-mcp 读取 26.2 mojmap 的 RenderPass、DeviceInfo、DeviceLimits、GpuBuffer、CloudRenderer、GlCommandEncoder、VulkanRenderPass、VulkanGpuBuffer。
- `GpuBuffer.USAGE_UNIFORM_TEXEL_BUFFER = 256`；BindGroupLayouts.CLOUD_INFO 使用 `UniformType.TEXEL_BUFFER` 与格式 `R8_SINT`。`RenderPass.setUniform` 可传整个 GpuBuffer 或 slice，管线 BindGroupLayout 指定 texel 格式。
- DeviceLimits 只有通用 allocation/texture/uniform alignment 等上限，没有单独 texel-buffer 大小/offset alignment 上限。不能把旧 GL SSBO limits 当作 Vulkan 能力。
- `GlCommandEncoder` 在 texel uniform 分支使用 `GL33C.glTexBuffer(target, format, buffer.handle)`，没有传 slice offset/range；`VulkanRenderPass` 创建 VkBufferView，使用 slice offset/length。直接将旧 SSBO slice 换成 texel slice 会产生双后端偏移差异。
- 后续优先采用整块 arena 绑定、shader 显式数据偏移；复用现有 GpuPoseArena、GpuRetirement 和 fence，不引入独立 Vulkan 资源管理。具体布局、容量、offset 元数据的生命周期尚待实施与验证。

## 已实现与 GREEN

- 移除 GpuStorageSupport 中 GL capability、GlBuffer 强制转换与 glBindBufferRange。能力取自原版 DeviceInfo/DeviceLimits，保持 storage opt-in 与实际激活像素诊断门槛。保留原 16MiB arena 上限，并受原版最大 allocation 约束。
- pose/remap/model 仍由既有 writer 生成相同字节；RGBA32_UINT texel channel 通过 uintBitsToFloat 读取 float 位模式，通过整数读取 overlay/light/remap。普通 UBO 变体、palette fallback、缓存、排序及 JNI 路径保留。
- arena 内增加每次 draw 的 16 字节偏移 UBO，基址使用 16 字节 texel 单位；offsets 与 pose 同 arena、同 fence 退休，无新资源管理层。按 native uniform alignment 对齐，绑定整个 arena，解决 GL 忽略 slice offset 的差异。新增字节计入上传预算和诊断；原有增量写入、之前姿态不被覆盖断言已按实际布局更新。
- 生产激活诊断用同一 shader/layout/bind，读取最大 arena 接近尾端的数据，验证实际容量；其执行结果仍须由真正运行环境提供。本地未启动该 GPU 诊断，不虚报像素结果。
- 删除唯一用途已经消失的 GlBufferAccessor 及其 Mixin 配置。加速目录不再引用原版 OpenGL 实现或 LWJGL GL API。
- `gpuRigidDataSmokeTest` 的 native shader contract 初始 RED（GL 专用扩展），见 S3-texel-shader-contract-red.log；迁移后既有字节打包、65-part remap、混合 model 数据及普通 UBO palette 断言全部 GREEN。
- `gpuShaderCompilationSmokeTest` 使用原版 GlslPreprocessor 和实际 Minecraft entity.vsh/imports/defines，经原版 GlslCompiler 编译五种生产变体到 SPIR-V；核对反射输出 offsets UBO 与 dim=buffer 数据入口。package-private 原版反射记录只在测试内读取，未为测试修改生产 AW。初次 fixture 编译失败见 S3-native-shader-and-storage.log；修正后 GREEN 见 S3-native-shader-and-storage-current.log（37s，另包含 native probe、rigid data、gpuAcceleration 全部 GREEN）。
