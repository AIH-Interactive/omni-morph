# 更新日志

## 1.0.0-alpha.2

### 新增

- 模型库上传、搜索、分类、收藏、下载与装备。
- 上传者和管理员可编辑模型基础信息。
- 需授权模型的授权管理，以及私有模型外观展示设置。
- 管理员模型管理、衣柜模型管理、举报与申诉处理。
- 模型库和衣柜模型回收站，支持恢复与彻底删除。
- 后端异常断连后的自动重连。
- 模型卡片和管理表格根据窗口大小调整每页容量。
- 简体中文界面翻译补齐，以及模型专用设置、轮盘编辑与内置控件的本地化。

### 修复与优化

- 兼容嵌套目录中的 Figura ZIP 模型，保留完整作者署名。
- 修复模型上传校验、可选标签及多行作者信息处理。
- 修复模型预览中的空白、实体渲染异常和模型专用设置预览缺失。
- 修复切换模型时旧状态请求导致的连接中断。
- 修复列表未返回屏蔽及删除状态的问题；支持解除屏蔽，屏蔽模型保留在上传者“我的模型”中。
- 优化 YSM 动画事件索引和兼容字段查询开销。
- 优化模型库卡片、管理表格、图标按钮及上传表单交互。

## 1.0.0-alpha.1

### 新增

- 建立 OmniMorph 独立品牌与版本体系，更新模组标识、图标和帮助界面。
- 支持 Minecraft 26.1.2 / Fabric / Java 25。
- 统一加载 Figura Avatar 与 YSM 模型，支持受支持格式的目录、ZIP 和加密 `.ysm` 文件。
- 接入 YSM 几何、动画控制器、Molang、纹理、声音、模型控件与动作轮盘。
- 提供 `ysm_model`、`ysm_actions` 接口，实现 Figura Lua 与 YSM 运行时联动。
- 支持 Figura Cloud 与 Protobuf 云端协议，以及模型资源分发和 YSM 动态状态同步。
- 提供模型加载阶段、下载与上传进度显示。
- 加入默认关闭的 SIMD / GPU 硬件加速选项，以及 Java 回退机制。
- 提供 Windows、Linux、macOS 和 Android 对应架构的原生库构建与打包。

### 修复与优化

- 异步准备本地与下载模型，避免旧加载结果覆盖新的模型选择。
- 修复“全部重新加载”后的本地模型恢复，以及模型切换后的广播与云端装备刷新。
- 将 YSM 面数复杂度接入原有模型统计和权限显示。
- 修复 YSM 移动动画混合、反三角函数角度单位及动画帧预算处理。
- 统一服务器地址与协议设置，限制非调试模式下的明文连接。
- 将默认模型数据目录统一为 `omnimorph`，兼容旧目录及配置迁移。
