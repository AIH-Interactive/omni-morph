## 1.0.0-alpha.6

- 开发阶段：优先推进 YSM 与 Figura 共用渲染性能优化。各阶段尚待验证，不代表性能验收或正式发布完成。

## 1.0.0-alpha.5

- YSM 动画对齐参考实现：控制器阶段顺序、手部 hold/use/swing 分阶段替换与暂停、旧格式循环覆盖、本地输入脉冲、原生动作状态表、默认回退动画、自转移与环路、起播过渡、解析失败语义、`math.*` 函数、`time_of_day` 相位、声音生命周期、身体/第一人称动画分域、过渡旋转四元数插值、事件回绕、关键帧采样细节、滤波器恢复与非有限值处理、纹理半透明判定、旧格式文件夹识别、骨骼可见键、多手部挂点链。
- 新增 252 个参考 `ysm.*` 查询名中缺失的 99 个（含武器/三叉戟/长矛/重锤族），以及 Bedrock `this` 关键字。
- 修复：芙宁娜拉弓蓄力姿态、右键矛无动作与矛姿态、战术酒狐走路/长按动作重播与资源激活范围、宇航员移动露出备用头盔、起步/停步闪出隐藏道具、开启“第一人称 Matrices”后 YSM 模型遮挡视野。
- 远端玩家状态同步（D025）：其他玩家的 YSM 模型可读取你的饥饿值、经验等级、飞行、移动输入和药水效果等级；仅经 Protobuf 协议发给声明 `YSM_DISPLAY` 能力的服务器，可在“网络”设置中关闭“向 YSM 模型分享玩家状态”。协议 `YsmState` 新增可选 `display` 字段（需配套后端）。
- Lua API：新增全局 `ysm_display`（读取任意玩家的上述状态及其 YSM 动作状态/控制器状态，未知为 nil）；`ysm_model` 新增只读状态机查询（动作状态、原生动画、手部动作、控制器状态/时间/状态名）。
- 真实游戏画面、声音、双客户端验收仍 `MANUAL/PENDING`。

## 1.0.0-alpha.4.1

- 第一人称：配装组合按相机相对全身姿态每帧重放一次（几何丢弃），身体挂点装饰的 RENDER/POST_RENDER、粒子与拖尾保持运行；基础与手臂的 part-to-world 矩阵按当前帧更新。
- 光影：自定义粒子管线按混合模式映射到 Iris 粒子程序；Iris 阴影阶段跳过自定义粒子的回调/提取、粒子组提交以及配装脚本的 POST_RENDER 发射，并剔除模型视图中的相机平移，修复开光影后拖尾/粒子偏离原位。
- LambDynamicLights：粒子动态光源通过公开 DynamicLightBehavior API 注册为世界光源；安装时内置光场停止注入以避免双重照明，世界切换后自动重新注册；未安装时输出一次回退警告并继续使用内置光场。
- 动态光源上限：超过后端 `outfit.limits` 的每穿戴者光源数时，只保留先前启用的前 N 个，其余粒子存活但不发光。`CustomParticle` 新增 `setLightInterval(n)` / `getLightInterval()` 及 `light = { interval = n }`：每隔 n 个可发光粒子只让一个成为动态光源，其余粒子仍正常显示；拖尾创建模板新增 Light interval 控件。
- 修复：点击/调整装饰后原版粒子与拖尾停在固定位置、粒子动态光源失效（关闭衣柜不再保留草稿世界预览；世界身体绘制固定 RENDER；part-to-world 矩阵每帧刷新；纸娃娃预览不再泄漏渲染模式）。
- Blockbench 骨架蒙皮：识别 armature/bone 节点，网格静止变换烘焙到骨架空间，按 boneWorld × inverse(bindWorld) 变形；支持加载后补充的蒙皮数据与骨架空间骨骼覆盖。
- 标准挂点回退：自定义 Figura/YSM 骨架缺少标准 Head/Body 名称时，按大小写别名或首个骨架节点回退，修复 Head 类装饰在自定义基础形象上不渲染。
- 诊断：移除临时 publish/accessory draw/挂点缺失日志；脚本错误仍会报告。
- 游戏内版本显示由 “1.0 Alpha 3” 修正为 “1.0 Alpha 4.1”。
- 真实客户端光影、混入加载与画面仍 `MANUAL/PENDING`。

- 修复衣柜在编辑实例被移除/切换后仍渲染旧挂点下拉导致 `OUTFIT_INSTANCE_MISSING` 崩溃；共享骨架节点按首次路径去重，避免第一人称手部捕捉重复节点时 `INVALID_OUTFIT_CONFIGURATION` 崩溃。

- 修复滑块保存值在控件定义注册阶段被临时 0..1 范围钳成 1（如 interval、lifetime、frame_ticks、light_interval），以及云端/外部状态更新后滑块位置不跟随的问题；恢复原始保存值并在 `setRange` 后重新规范化，滑块现在会同步外部控件值。

- 修复 Iris 阴影 pass 仍对实体执行配装骨架捕捉/绑定，导致 `SkeletonIndex.bindParts` 在阴影视图上抛出 `INVALID_OUTFIT_CONFIGURATION` 崩溃；阴影阶段现在跳过配装提交，主视图渲染不受影响。

- 修复加载部分模型后，同一资源身份缓存的骨架与当前原生 part 图不一致，`SkeletonIndex.bindParts` 抛 `INVALID_OUTFIT_CONFIGURATION` 的问题；缓存绑定失败时会重新捕捉当前图，而不是让实体渲染崩溃。

- 网络配置默认改为允许网络访问（`allow_networking=true`），访问限制默认改为“无限制”（`networking_restriction=2`，NONE）。

- 我的形象集本地源新增“导出为 ZIP”：支持本地形象与装饰，默认写入 `omnimorph/export`（MISC 的“导出目录”可修改），文件名为 `avatar_名称.zip` / `cosmetic_名称.zip`（`.ysm` 保留扩展名，重名追加 `(2)`），保留源目录结构；导出在后台执行并显示结果。

- 虚拟锚点编辑器补充“确定”按钮，应用当前编辑并返回骨骼树，避免只能通过返回键离开。

- 优化虚拟锚点创建/编辑：位置与旋转字段实时更新预览中的锚点坐标轴标记，移除缩放字段并将锚点缩放固定为 1，同时保留“确定”按钮返回骨骼树。

- 修复模型库预览加载装饰脚本时 `cosmetic_controls` 为 nil，导致 `newToggle` 等控件声明报错的问题；预览环境现在提供真实控件 API，但不写入本地持久化。

- 修复 YSM/非 Figura 基础在第一人称手部渲染时仍调用 `prepareFiguraBase`，触发 `INVALID_OUTFIT_CONFIGURATION` 崩溃；现在只有 Figura 基础才走该配装手臂路径。

- 恢复衣柜预览底部原有状态栏（模型大小、纹理、脚本、后端连接四点）及加载错误指示，重新加入 `StatusWidget` / `LoadingErrorWidget`。

- 本地配装形象加载失败时立即清理旧的 GUI/世界预览并显示错误，不再继续展示上一个模型；成功加载后仍自动进入世界预览。

- 关闭衣柜时保留当前本地配装的世界预览（不提交、不广播），再次打开或清除时由预览生命周期回收。

- 重新打开衣柜恢复本地配装世界预览时，以服务器已提交配装作为清洗基准，保留当前本地草稿的未保存状态，发布按钮不再被误禁用。

- 本地配装世界预览改用正常世界粒子/动态光管线：世界预览实例不再绑定 GUI `PreviewParticleScope`，原生粒子、粒子和动态光照随玩家正常 tick/注册。

## 1.0.0-alpha.3

### 新增

- 形象与缩略图直接共用 `cache/avatars`：形象使用 `.oma`，缩略图按实际格式使用 `.png` / `.jpg`；旧缓存按需迁移，密钥及账号元数据保持独立，后续装饰品另设目录。
- 缓存格式约定：形象集数据使用 `.omc`，装饰品预留 `.oms` 与 `cache/cosmetic` 目录；旧 `.omc` 模型缓存按需改名为 `.oma`，保留数据与密钥。
- 衣柜新增“配装 / 我的形象集”垂直标签，本地与云端来源独立于形象/部件模式；2.0 装饰区域仅提供“敬请期待（2.0实装）”布局。
- 模型库改为“加入衣柜”，本人投稿默认加入账号云端形象集；加入、预览与正式启用相互独立。
- 云端形象集提供配装候选、手动缓存和按权限管理；全局“其它 → 自动缓存形象集”默认关闭。
- 通用模型缓存采用压缩、加密与封装，降低直接解包提取的便利性；缓存使用仍校验账号与模型权限。
- Figura/YSM 只读骨骼树支持默认折叠、名称搜索、搜索状态恢复及横向滚动；选中部件显示选择框，其余部分半透明。
- 当前已启用形象可独立设置是否对外展示，适用于公开及私有模型，不改变模型库条目权限。

- 衣柜来源与用途均增加默认“全部”：合并本地/云端资源，配装仍仅显示候选；“部件”改称“装饰”，保留 2.0 占位。

- 补齐已缓存、未缓存、下载中及缓存失败的中英文翻译，并纳入翻译键检查。

## 1.0.0-alpha.1

### 新增

- 建立 OmniMorph 独立品牌与版本体系，更新模组标识、图标和帮助界面。
- 支持 Minecraft 26.1.2 / Fabric / Java 25。
- 统一加载 Figura Avatar 与 YSM 模型，支持受支持格式的目录、ZIP 和加密 `.ysm` 文件。
- 接入 YSM 几何、动画控制器、Molang、纹理、声音、模型控件与动作轮盘。
- 提供 `ysm_model`、`ysm_actions` 接口，实现 Figura Lua 与 YSM 运行时联动。
- 支持 Figura Cloud 与 Protobuf 云端协议，以及模型资源分发和 YSM 动态状态同步。
- 提供模型加载阶段、下载与上传进度显示。
- 加入默认关闭的 SIMD / GPU 硬件加速选项，以及 Java 回退机制。
- 提供 Windows、Linux、macOS 和 Android 对应架构的原生库构建与打包。

- 将 YSM 面数复杂度接入原有模型统计和权限显示。

- 统一服务器地址与协议设置，限制非调试模式下的明文连接。
- 将默认模型数据目录统一为 `omnimorph`，兼容旧目录及配置迁移。
