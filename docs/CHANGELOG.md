## 1.0.0-alpha.4

- 支持原版/Figura/YSM 基础上的多实例装饰、独立控件/轮盘、稳定骨架挂点、虚拟挂点、内部骨骼覆盖及拖尾。
- 新增 CustomParticle 的 Billboard/Layered/Ribbon、静态/精灵贴图、UV 平铺/拉伸、内置轨迹、受限 Lua 回调和可选动态光源；预算由后端 `outfit.limits` 配置。
- 衣柜接入装饰、预设、创建与投稿；授权缓存复用固定修订。后台衣柜管理和权限页的其他玩家预览按在线实体条件复用原预览，否则隔离预览。
- 整套 Apply 使用 CAS/幂等提交与原子驻留发布；独立授权观察者、实例持久状态和修订通知，兼容旧客户端基础投影与冻结 v1。
- 既有 YSM 缺失基础动作使用受限默认模板；作者动作优先，模板不改变原文件及旧同步索引。
- 计划完成后修正 YSM 公共路径：共根手臂按左右子树绘制、作者动画后叠加头部跟随、睡眠按床朝向整体旋转；滤波初值保持输入姿态。无模型名/hash/作者特化。
- 第一人称：装饰组合按相机相对全身姿态每帧重放一次（几何丢弃），身体挂点装饰的 RENDER/POST_RENDER、粒子与拖尾保持运行；本地身体与手臂的 part-to-world 矩阵按当前帧刷新。
- 光影：自定义粒子管线按混合模式映射到 Iris 的粒子程序；Figura 实体管线保持映射。
- LambDynamicLights：粒子动态光源通过其公开 DynamicLightBehavior API 注册为世界光源行为；安装时内置光场停止注入以避免双重照明，世界切换后自动重新注册；未安装时输出一次回退警告并继续使用内置光场。
- 动态光源上限：超过后端 `outfit.limits` 的每穿戴者光源数时，只保留先前启用的前 N 个，其余粒子保持存活但不发光。
- 修复：调整/点击装饰后拖尾与原版粒子停在固定位置、粒子动态光源失效（关闭衣柜后不再保留草稿世界预览；世界身体绘制始终使用 RENDER；part-to-world 矩阵每帧刷新；纸娃娃预览不再泄漏渲染模式）。
- 移除衣柜/装饰渲染的临时诊断日志；脚本错误仍会报告。
- [验收记录](ALPHA4_ACCEPTANCE.md)：自动验证与真实客户端待验项分别记录，真实双客户端/GUI/GPU/光照/性能及上述手部/头发/睡姿画面对照仍 `MANUAL/PENDING`。

## 1.0.0-alpha.3

### 新增

- 形象与缩略图直接共用 `cache/avatars`：形象使用 `.oma`，缩略图按实际格式使用 `.png` / `.jpg`；旧缓存按需迁移，密钥及账号元数据保持独立，后续装饰品另设目录。
- 缓存格式约定：形象集数据使用 `.omc`，装饰品预留 `.oms` 与 `cache/cosmetic` 目录；旧 `.omc` 模型缓存按需改名为 `.oma`，保留数据与密钥。
- 衣柜新增“配装 / 我的形象集”垂直标签，本地与云端来源独立于形象/部件模式；2.0 装饰区域仅提供“敬请期待（2.0实装）”布局。
- 模型库改为“加入衣柜”，本人投稿默认加入账号云端形象集；加入、预览与正式启用相互独立。
- 云端形象集提供配装候选、手动缓存和按权限管理；全局“其它 → 自动缓存形象集”默认关闭。
- 通用模型缓存采用压缩、加密与封装，降低直接解包提取的便利性；缓存使用仍校验账号与模型权限。
- Figura/YSM 只读骨骼树支持默认折叠、名称搜索、搜索状态恢复及横向滚动；选中部件显示选择框，其余部分半透明。
- 当前已启用形象可独立设置是否对外展示，适用于公开及私有模型，不改变模型库条目权限。

### 修复与优化

- 衣柜来源与用途均增加默认“全部”：合并本地/云端资源，配装仍仅显示候选；“部件”改称“装饰”，保留 2.0 占位。
- 修复选中配装预览后公开和私有形象的展示按钮持续禁用：独立跟踪已启用形象，避免逐 tick 取消状态读取和保存请求。

- 配装移出操作改为本地/云端条目的右键菜单；常用操作置前并按功能分隔，新建与文件夹按钮仅在形象集显示，骨骼刷新移至搜索框旁。配装条目加高，左上角仅保留类型图标；模型库悬浮提示补充完整类型文本。
- 修复配装点击条目后预览不切换；新增预览统一使用 Figura 原版实体 GUI 渲染，选择预览不自动换装。
- 形象集卡片、列表与预览比例及预览高度对齐模型库；来源、形象/部件模式及格式筛选统一收纳到“+”，操作使用预览下方的图标按钮。
- 补齐已缓存、未缓存、下载中及缓存失败的中英文翻译，并纳入翻译键检查。
- 修复垂直标签文字丢失；统一来源与模型类型图标、单行预览说明，并合并重复发布操作。

云端成员移除与公开形象展示开关需要配套后端更新。真实游戏窗口及多人视觉验收仍为 `MANUAL/PENDING`。

## 1.0.0-alpha.1

### 新增

- 建立 OmniMorph 独立品牌与版本体系，更新模组标识、图标和帮助界面。
- 支持 Minecraft 26.1.2 / Fabric / Java 25。
- 统一加载 Figura Avatar 与 YSM 模型，支持受支持格式的目录、ZIP 和加密 `.ysm` 文件。
- 接入 YSM 几何、动画控制器、Molang、纹理、声音、模型控件与动作轮盘。
- 提供 `ysm_model`、`ysm_actions` 接口，实现 Figura Lua 与 YSM 运行时联动。
- 支持 Figura Cloud 与 Protobuf 云端协议，以及模型资源分发和 YSM 动态状态同步。
- 提供模型加载阶段、下载与上传进度显示。
- 加入默认关闭的 SIMD / GPU 硬件加速选项，以及 Java 回退机制。
- 提供 Windows、Linux、macOS 和 Android 对应架构的原生库构建与打包。

### 修复与优化

- 异步准备本地与下载模型，避免旧加载结果覆盖新的模型选择。
- 修复“全部重新加载”后的本地模型恢复，以及模型切换后的广播与云端装备刷新。
- 将 YSM 面数复杂度接入原有模型统计和权限显示。
- 修复 YSM 移动动画混合、反三角函数角度单位及动画帧预算处理。
- 统一服务器地址与协议设置，限制非调试模式下的明文连接。
- 将默认模型数据目录统一为 `omnimorph`，兼容旧目录及配置迁移。
