## 移植清单

### 1. 通用左侧导航

新增（可直接复制）：
- `common/.../gui/widgets/navigation/`：`NavigationRoute`（条目）、`NavigationTree`（菜单树、折叠、默认页、路径、管理员条目可见性）、`NavigationLayout`（宽度、滚动、命中几何；逻辑单位：图标栏 28，展开最大 140，行高 18）、`SideNavigationWidget`（绘制与事件；图标复用 `textures/gui` 下的 `panels.png`、`library.png`、`icon.png`）。
- `common/.../gui/screens/NavigationScreens.java`：导航目标到页面的映射。
- 语言文件：`gui.navigation.*`（16 个键）。

修改：
- `AbstractPanelScreen`：用 `SideNavigationWidget` 替换 `PanelSelectorWidget`。导航只作为输入监听器加入，在正文之后绘制，并优先接收点击和滚动。新增 `usesSideNavigation()`、`navigationRoute()`、`navigate()`、`openNavigationRoute()`，以及常量 `SIDE_MARGIN = 30`。
- `WardrobeScreen` / `WardrobeLayout`：
  - 删除左侧“配装 / 我的形象集”竖排 Tab、右侧“预览 / 默认 / 骨骼”竖排 Tab，以及宽窗口下的“默认 / 骨骼”按钮。
  - 新增 `selectNavigationRoute` 与 `openNavigationRoute`。
  - 紧凑配装改为在宽度小于 `WIDE_WIDTH`（560）时生效，不再判断 CompactMode。
  - 右侧保留 28 的边距，与 Penpot 一致。
- `ModelLibraryScreen`：
  - 删除 `LibrarySectionTabs`。
  - 新增 `selectNavigationRoute`、`openNavigationRoute`。
  - 新增 `pendingSection`：从其他页面跳到上传或管理时，等服务能力返回后再打开。
  - 用 `setAdministratorVisible(capabilities.adminLoginAvailable())` 控制管理员条目。
- `ModelUploadScreen`、`ModelLibraryAdminScreen`、`LibraryFormScreen`：删除分区 Tab；导航经由保留的模型库页面返回，请求进行中忽略导航；常量 `NAVIGATION_INSET = 30`。
- `PermissionsScreen`、`ConfigScreen`、`HelpScreen`：接入导航；保留窗口中线，只收窄内容宽度，避开导航栏。
- 二级页面（`KeybindScreen`、`SoundScreen`、`NetworkFilterScreen`、`AvatarWizardScreen`、`DocsScreen`、`BrowserScreen`、`ProfileScreen`、`ModelFilePickerScreen`）：`usesSideNavigation()` 返回 true；居中内容使用 `SIDE_MARGIN`；文件选择器整体右移 `SIDE_MARGIN`。
- 删除：`LibrarySectionTabs`、`LibrarySectionLayout`、`VerticalWardrobeTab`。
- 后端 `src/api/library/models.rs`：`admin_login_available` 改为“当前请求玩家的 UUID 在管理员配置中”。

### 2. 固定卡片与容量

- `ModelLibraryLayout`：
  - 卡片固定为 90×108（封面 90×90，名称行 18），间距 6。
  - 列数 = floor((Aw+6)/96)，行数 = floor((Ah+6)/114)。
  - 删除 compact 系列方法；新增 `pageKeepingFirst`。
- `ModelCardWidget`：
  - 重写为共享卡面，提供 `drawFace`、`isOnMenu`、`openMenu`、`statusTooltip`。
  - 状态图标顺序为：屏蔽、需授权、私有或公开；公开使用 `library_visibility.png` 的睁眼图标。
  - 三点按钮打开 `ContextMenu`，菜单项为“举报 / 收藏”。
  - 名称过长时以“…”截断。
- `ModelLibraryGrid`：固定使用细滚动条，`cardAreaWidth(width) = width - 7`。
- `ModelLibraryScreen`：按固定卡片计算容量；容量变化时用 `pageKeepingFirst` 保留当前页的第一项。
- `WardrobeCollectionGrid` 使用共享卡面，新增 `cardActions`。`WardrobeScreen` 接入举报页面，并新增 `toggleCloudFavorite`。
- 语言文件：`gui.library.card_menu.more/report/favorite`。

### 3. 游戏世界化身可见性（主要在后端）

- 后端 `library_policy.rs`：`can_render_equipment` 对非私有模型改为按佩戴者的使用权判断，观看者不需要自己的授权；私有模型仍只能由上传者佩戴，并遵循其显示设置；被屏蔽的模型一律不显示。
- 后端 `distribution.rs`、`outfit_sources.rs`：授权查询的对象改为佩戴者。
- 后端 `library_equipment.rs` / `models.rs`：
  - `show_private_equipment` 改为可空。
  - 请求未指定时保留已保存的设置；没有已保存设置时，私有模型默认显示。
  - 请求明确指定时照旧写入并原样返回。
- 客户端 `LibraryEquipmentService.enable(UUID, Boolean)`：值为 null 时不发送显示设置。`WardrobeScreen.enableSelection` 只有在模型已装备、设置已知时才传入该值。
- 不变：模型库可见性、下载、使用、编辑、授权管理的判断。

### 4. 第一人称手臂崩溃

- `SkeletonPose.nativeToEntity(Matrix4fc)`：安全求逆，矩阵不可逆时返回空。
- `PlayerRendererMixin`：第一人称 Figura 手臂路径改用这个方法；不可逆的帧只绘制原生手臂。
- 其他版本：凡是用 `new Matrix4f(pose).invert()` 作为 `captureFiguraArm` 参数的地方，都要同样替换。

### 5. 版本与文档

- `gradle.properties`、四份 README：改为 `1.0.0-alpha.10`。
- `docs/CHANGELOG*.md`（四种语言）：新增 alpha.10，补写 alpha.7–9。
