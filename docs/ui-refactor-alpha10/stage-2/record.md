# 阶段 2：固定卡片与自适应容量

日期：2026-11-09。分支 `main`。

## 实现

- 卡片尺寸固定为 90×108 逻辑单位：上部是 90×90 的方形封面，下部是 18 高的名称行。卡片不随列表宽高拉伸。
- 封面左上显示类型图标和类型名（Figura / YSM），复用项目已有的类型资源。
- 封面左下只显示状态图标，按设计顺序为：屏蔽、需授权、私有或公开（两者互斥）。公开状态新增“睁眼”图标，复用 `library_visibility.png`。所有尺寸都不显示状态文字，图标含义写在卡片提示里。
- 名称行右侧是三点按钮，点开为“举报 / 收藏”文字菜单，使用现有的 `ContextMenu`。收藏仍受 `allows("favorite")` 约束。长名称以“…”截断，完整名称在提示中显示。
- 删除了卡片上常驻的作者、上传者、分类、下载与收藏统计行，以及“☆”“!”按钮。这些信息仍在悬停提示和详情区中。
- 衣柜“我的形象集”使用同一套卡片外观。云端条目的三点菜单接到现有的举报页面和收藏接口；本地条目没有菜单。
- 容量计算：列数 = floor((Aw + 6) / 96)，行数 = floor((Ah + 6) / 114)，每页数量 = 列数 × 行数，不超过服务器上限。原型中的 3、6、8 只是示例。卡片区固定使用细滚动条（宽 7），衣柜形象集保持原有的 18 宽滚动条区。
- 区域小于一张卡片时仍显示一张原尺寸卡片，超出部分被裁剪；正常尺寸下有原有的“窗口过小”提示兜底。
- 每页数量变化时，改为跳到仍包含当前页第一项的那一页（`pageKeepingFirst`），不再回到第 1 页。选中项照旧按 ID 保留。
- 不再受 CompactMode 限制：模型库和形象集删除了“紧凑双列小卡”的分支。紧凑模式下的 3/5 按钮上限没有改动，不属于本阶段。
