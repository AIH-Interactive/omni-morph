## 1.0.0-alpha.4.1

- 1인칭: 의상 컴포지션을 카메라 기준 전신 자세로 매 프레임 한 번 재생(지오메트리는 폐기)하여 신체 장착 장식의 RENDER/POST_RENDER, 파티클, 트레일을 동작시킵니다. 신체와 팔의 part-to-world 행렬을 현재 프레임에 맞게 갱신합니다.
- 셰이더: 커스텀 파티클 파이프라인을 블렌드별로 Iris 파티클 프로그램에 매핑하고, Iris 그림자 패스에서는 커스텀 파티클 콜백/추출, 그룹 제출, 의상 스크립트 POST_RENDER 발화을 건너뛰며 모델 뷰에서 카메라 이동을 제거하여 셰이더 사용 시 트레일/파티클이 원래 위치에서 벗어나는 문제를 수정합니다.
- LambDynamicLights: 파티클 동적 광원을 공개 DynamicLightBehavior API로 월드 광원으로 등록합니다. 설치 시 이중 조명을 피하기 위해 내장 라이트 필드 주입을 중지하고 월드 변경 후 재등록합니다. 미설치 시 한 번 폴백 경고를 기록하고 내장 필드를 계속 사용합니다.
- 파티클 광원 상한: `outfit.limits`의 착용자당 상한을 초과하면 먼저 활성화된 N개만 점등되고 나머지는 살아 있지만 꺼진 상태를 유지합니다. `CustomParticle`에 `setLightInterval(n)` / `getLightInterval()` 및 `light = { interval = n }`을 추가해 광원 가능한 파티클 n개마다 하나만 동적 광원이 되도록 했습니다(나머지는 계속 표시). 트레일 생성 템플릿에 Light interval 컨트롤을 추가했습니다.
- 의상 조정/클릭 후 트레일과 바닐라 파티클이 고정 위치에 멈추고 파티클 동적 광원이 꺼지는 문제를 수정했습니다(옷장을 닫은 뒤 드래프트 월드 프리뷰를 유지하지 않음, 월드 신체 렌더는 항상 RENDER, part-to-world 행렬 매 프레임 갱신, 종이인형 프리뷰가 렌더 모드를 누출하지 않음).
- Blockbench 아마추어 스키닝: armature/bone 노드를 인식하고 메시의 정지 변환을 아마추어 공간에 베이크하며 boneWorld × inverse(bindWorld)로 변형합니다. 로딩 후 추가된 스키닝 데이터와 아마추어 공간 본 오버라이드를 지원합니다.
- 표준 앵커 폴백: 표준 Head/Body 이름이 없는 커스텀 Figura/YSM 리그는 대소문자 무시 별칭 또는 첫 번째 리그 노드로 폴백하여 커스텀 베이스에서 Head 계열 장식(예: hat)이 렌더링되지 않는 문제를 수정합니다.
- 진단: 임시 publish/accessory draw/마운트 누락 로그를 제거했습니다. 스크립트 오류는 계속 보고됩니다.
- 게임 내 버전 표시를 “1.0 Alpha 3”에서 “1.0 Alpha 4.1”로 수정했습니다.
- 실제 클라이언트 셰이더, 믹스인 로딩 및 화면 검증은 `MANUAL/PENDING`입니다.

- 편집 인스턴스가 제거/교체된 뒤 오래된 앵커 드롭다운이 렌더링되어 `OUTFIT_INSTANCE_MISSING`으로 옷장이 충돌하는 문제를 수정했습니다. 공유 스켈레톤 노드는 첫 경로 기준으로 중복 제거하여 1인칭 손 캡처가 `INVALID_OUTFIT_CONFIGURATION`으로 실패하지 않게 했습니다.

- 컨트롤 정의의 임시 0..1 범위 때문에 `setRange` 전에 저장된 슬라이더 값(interval, lifetime, frame_ticks, light_interval 등)이 1로 클램프되는 문제와, 클라우드/외부 상태 변경에 슬라이더가 따라가지 않는 문제를 수정했습니다. 복원된 원본 값을 유지하고 `setRange` 후 다시 정규화하며, 외부에서 변경된 컨트롤 값에 슬라이더를 동기화합니다.

- Iris 그림자 패스에서도 엔티티의 의상 스켈레톤을 캡처/바인딩하여 `SkeletonIndex.bindParts`가 그림자 뷰에서 `INVALID_OUTFIT_CONFIGURATION`을 던지며 충돌하는 문제를 수정했습니다. 그림자 패스에서는 의상 제출을 건너뛰고 메인 뷰 렌더링은 유지합니다.

- 일부 모델을 로드한 뒤 동일 리소스 ID의 캐시된 스켈레톤이 현재 네이티브 part 그래프와 일치하지 않아 `SkeletonIndex.bindParts`가 `INVALID_OUTFIT_CONFIGURATION`을 던지는 문제를 수정했습니다. 캐시 바인딩 실패 시 현재 그래프를 다시 캡처하여 엔티티 렌더링이 충돌하지 않도록 했습니다.

- 네트워크 설정 기본값을 “허용”(`allow_networking=true`), 제한을 “없음”(`networking_restriction=2`, NONE)으로 변경했습니다.

- 내 컬렉션의 로컬 소스에 “ZIP으로 내보내기”를 추가했습니다. 아바타와 장식을 지원하며 기본적으로 `omnimorph/export`(MISC의 “내보내기 디렉터리”에서 변경 가능)에 `avatar_이름.zip` / `cosmetic_이름.zip` 형식으로 저장합니다(`.ysm`은 확장자를 유지하고 중복 시 `(2)` 추가). 원본 디렉터리 구조를 유지하며 내보내기는 백그라운드에서 실행되고 결과를 표시합니다.

- 가상 앵커 편집기에 “확인” 버튼을 추가하여 현재 편집을 적용하고 본 계층으로 돌아갈 수 있게 했습니다.

- 가상 앵커 생성/편집을 개선했습니다. 위치·회전 필드가 미리보기의 앵커 좌표축 마커를 실시간 갱신하고, 크기 필드를 제거하여 앵커 크기를 1로 고정했습니다. “확인” 버튼으로 본 계층으로 돌아갑니다.

- 모델 라이브러리 장식 미리보기에서 `cosmetic_controls`가 nil이라 `newToggle` 등 컨트롤 선언이 실패하는 문제를 수정했습니다. 미리보기에서도 실제 컨트롤 API를 제공하지만 값을 저장하지 않습니다.

- YSM/비-Figura 베이스의 1인칭 손 렌더링에서 `prepareFiguraBase`를 호출해 `INVALID_OUTFIT_CONFIGURATION`으로 충돌하는 문제를 수정했습니다. 의상 손 경로는 이제 Figura 베이스에만 적용됩니다.

- 의상실 미리보기 하단의 상태 표시줄(모델 크기, 텍스처, 스크립트, 백엔드 연결 4개 지점)과 로딩 오류 표시를 복원하고 `StatusWidget` / `LoadingErrorWidget`을 다시 추가했습니다.

- 로컬 의상 베이스 로드에 실패하면 이전 GUI/월드 미리보기를 즉시 지우고 오류를 표시하여 이전 모델이 남지 않게 합니다. 성공한 경우에는 기존처럼 자동으로 월드 미리보기로 들어갑니다.

- 의상실을 닫은 뒤에도 현재 로컬 의상의 월드 미리보기를 유지합니다(커밋/브로드캐스트 없음). 다시 열거나 지울 때 미리보기 수명 주기로 정리됩니다.

- 의상실을 다시 열어 로컬 의상 월드 미리보기를 복원할 때 서버에 커밋된 의상을 기준으로 사용하고 로컬 초안의 미저장 상태를 유지하여 게시 버튼이 잘못 비활성화되지 않게 합니다.

- 로컬 의상 월드 미리보기가 일반 월드 파티클/동적 조명 경로를 사용합니다. 미리보기 인스턴스는 GUI `PreviewParticleScope`를 바인딩하지 않아 네이티브 파티클, tick, 동적 조명이 플레이어를 정상적으로 따라갑니다.

## 1.0.0-alpha.3

### 추가

- 형상과 썸네일을 `cache/avatars` 바로 아래에 함께 저장. 형상은 `.oma`, 이미지는 실제 형식에 맞는 `.png` / `.jpg`를 사용하며 기존 캐시는 필요할 때 이전합니다. 키와 계정 정보는 분리하고 향후 장식품은 별도 디렉터리를 사용합니다.
- 컬렉션 정보는 `.omc`를 사용하고 장식품용 `.oms`와 `cache/cosmetic`을 예약. 기존 `.omc` 모델 캐시는 데이터와 키를 유지하며 `.oma`로 이전합니다.
- ‘코디 / 내 컬렉션’ 세로 탭과 독립적인 로컬/클라우드 출처 및 형상/부품 모드. 2.0 장식 기능은 구현 예정 안내와 레이아웃만 제공합니다.
- 모델 라이브러리를 ‘옷장에 추가’로 변경하고 본인 업로드를 계정의 클라우드 컬렉션에 자동 추가. 추가와 미리보기는 장착을 바꾸지 않습니다.
- 코디 후보, 수동 캐시, 권한에 따른 클라우드 모델 관리. 자동 캐시는 전체 설정의 ‘기타’로 통합하고 기본값은 끄기로 설정.
- 공통 캐시를 압축·암호화한 컨테이너로 저장하여 단순 압축 해제를 통한 추출을 억제. 계정과 모델 권한 검사는 유지.
- 읽기 전용 Figura/YSM 뼈대 트리에 기본 접힘, 이름 검색, 펼침 상태 복원과 가로 스크롤 추가. 선택 부위는 테두리로 표시하고 나머지는 반투명 처리.
- 현재 장착한 형상의 외부 표시를 공개 모델에서도 라이브러리 공개 설정과 별도로 변경 가능.

### 수정 및 개선

- 출처와 용도에 기본값 ‘전체’ 추가. 로컬·클라우드를 함께 표시하되 코디는 후보만 표시하며, ‘부품’을 ‘장식’으로 변경하고 2.0 안내 유지.
- 미리보기 선택 후 공개·비공개 형상의 외부 표시 버튼이 비활성화되는 문제 수정. 실제 장착 상태를 별도로 추적하여 매 tick 조회·저장 요청이 취소되지 않도록 변경.

- 코디에서 제거를 로컬/클라우드 항목의 우클릭 메뉴로 이동. 자주 쓰는 작업을 앞에 두고 기능별로 구분하며 생성/폴더 작업은 컬렉션에서만 표시합니다. 뼈대 새로고침은 검색 옆으로 옮기고 항목 높이를 늘려 왼쪽 위 형식 아이콘 하나만 표시합니다. 라이브러리 툴팁에 전체 형식 이름을 추가.
- 코디 항목을 선택해도 미리보기가 바뀌지 않는 문제 수정. 추가된 미리보기는 Figura 기본 엔티티 GUI 렌더링을 사용.
- 컬렉션 카드, 목록/미리보기 비율과 높이를 라이브러리에 맞춤. 출처, 형상/부품 모드와 형식 필터를 ‘+’로 모으고 아이콘 작업을 미리보기 아래로 이동.
- 캐시 상태의 중국어·영어 번역을 보완하고 번역 키 검사를 확장.
- 세로 탭 글자 누락 수정. 출처/형식 아이콘과 한 줄 정보 표시를 통일하고 중복 게시 작업 정리.

클라우드 컬렉션 제거와 공개 형상 표시 전환에는 대응하는 백엔드 업데이트가 필요합니다. 실제 게임 창과 멀티플레이 시각 검증은 `MANUAL/PENDING`입니다.

## 1.0.0-alpha.2

### 추가

- 모델 라이브러리 업로드, 검색, 분류, 즐겨찾기, 다운로드 및 장착.
- 업로더와 관리자의 모델 기본 정보 편집.
- 허가가 필요한 모델의 사용 권한 관리와 비공개 모델 외형 공유 설정.
- 관리자 모델 관리, 옷장 모델 관리, 신고 및 이의 신청 처리.
- 라이브러리·옷장 모델 휴지통과 복원·영구 삭제 기능.
- 예기치 않은 백엔드 연결 끊김 이후 자동 재연결.
- 창 크기에 따라 조정되는 모델 카드와 관리 표의 페이지당 표시 수.
- 중국어 간체 인터페이스 번역 보완과 모델 전용 설정, 휠 편집, 내장 컨트롤의 현지화.
- 프로젝트 소개와 변경 기록을 중국어 간체, 일본어, 영어, 한국어로 제공.

### 수정 및 개선

- 중첩 폴더 안의 Figura ZIP 모델을 지원하고 전체 제작자 정보를 유지하도록 개선.
- 모델 업로드 검증, 선택 사항인 태그, 여러 줄 제작자 정보 처리를 수정.
- 빈 미리보기, 엔티티 렌더링 예외, 모델 전용 설정에서 미리보기가 표시되지 않는 문제를 수정.
- 모델 전환 시 이전 상태 요청으로 연결이 끊기는 문제를 수정.
- 모델 목록에 차단·삭제 상태가 반환되지 않는 문제를 수정. 차단 해제를 지원하고 차단된 모델을 업로더의 ‘내 모델’ 목록에 유지.
- YSM 애니메이션 이벤트 인덱싱과 호환 필드 조회 부하를 줄임.
- 모델 라이브러리 카드, 관리 표, 아이콘 버튼, 업로드 양식의 조작을 개선.
- 클라이언트와 백엔드 GitHub Actions 워크플로를 수동 실행 전용으로 변경.

## 1.0.0-alpha.1

### 추가

- OmniMorph 독립 브랜드와 버전 체계를 도입하고 모드 식별자, 아이콘, 도움말 화면을 갱신.
- Minecraft 26.1.2 / Fabric / Java 25 지원.
- Figura Avatar와 YSM 모델 로딩 통합. 지원되는 형식의 폴더, ZIP 및 암호화된 `.ysm` 파일 지원.
- YSM 지오메트리, 애니메이션 컨트롤러, Molang, 텍스처, 소리, 모델 컨트롤, 액션 휠 도입.
- Figura Lua와 YSM 런타임을 연동하는 `ysm_model`, `ysm_actions` 인터페이스.
- Figura Cloud 및 Protobuf 프로토콜, 모델 리소스 배포, YSM 동적 상태 동기화.
- 모델 로딩 단계와 다운로드·업로드 진행 상황 표시.
- 기본적으로 꺼져 있는 SIMD / GPU 하드웨어 가속과 Java 대체 처리.
- Windows, Linux, macOS, Android의 지원 아키텍처용 네이티브 라이브러리 빌드 및 패키징.

### 수정 및 개선

- 로컬 모델과 다운로드한 모델을 비동기로 준비하여 이전 로딩 결과가 새 선택을 덮어쓰지 않도록 개선.
- ‘모두 다시 불러오기’ 이후 로컬 모델 복원, 모델 전환 알림, 클라우드 장착 정보 갱신을 수정.
- YSM 면 수 기반 복잡도를 기존 모델 통계와 권한 표시에 통합.
- YSM 이동 애니메이션 혼합, 역삼각함수의 각도 단위, 애니메이션 프레임 예산 처리를 수정.
- 서버 주소와 프로토콜 설정을 통합하고 디버그 모드 외의 평문 연결을 제한.
- 기본 모델 데이터 폴더를 `omnimorph`로 통일하고 이전 폴더와 설정의 마이그레이션을 지원.
