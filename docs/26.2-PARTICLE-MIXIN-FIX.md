# 26.2 ParticleGroup Mixin 修复

日期：2026-11-04。分支：26.2 -> origin/26.2。

## 根因与修改

- 原版 `ParticleGroup.add(Particle)` 返回 boolean，旧注入处理器仍使用 CallbackInfo，真实 Mixin APPLY 抛出 `CallbackInfoReturnable is required`。
- 原版使用 ArrayDeque，并在容量已满或 reservoir sampling 拒收时返回 false；旧 EvictingQueue 淘汰分支不会运行。
- 生产注入改用 CallbackInfoReturnable<Boolean>，在 RETURN 仅清理被拒收的 CustomParticle，释放其存活名额、纹理及引擎 owner tracking；不移除已接收的粒子，不改变原版接收规则。
- 静态工具新增目标返回值与回调类型匹配检查。旧粒子测试的反射直调/EvictingQueue 改为真实原版 ParticleGroup + 生产 Mixin，由现有本地 agent 实际变换。
- 首次复现发现 agent 的零长度变换结果会被 JVM 忽略；改用非空无效字节，使变换失败明确成为 ClassFormatError，不能继续用未变换目标制造通过结果。
