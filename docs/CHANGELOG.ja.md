## 1.0.0-alpha.11

- YSM の一人称武器置換に対応。作者の左右の手ロケーターの表示設定とアニメーションに従い、身体モデルの手持ち装備を描画します。持ち替え動作、発光子ボーン、バニラ表示への復帰、独立した腕のポーズを維持します。
- 表示中 Avatar の参照を統一。ドラフトのカメラ/FOV、入力、Lua キー、炎と輪郭に反映し、バニラプレビューの優先順位、正式装備・同期・権限の識別と正式 HUD ホイールを維持。
- 配装ドラフトの一人称アイテム置換を修正。アイテムイベントと手の描画は、正式装備の Avatar ではなく表示中のローカルドラフトを使用します。
- 一人称：左右の通常の手持ちアイテムに Figura ITEM_RENDER 置換を追加。nil／Item 以外の戻り値ではバニラ描画を維持。
- カメラ：Lua `renderer:setFOV` を現在のバニラ視野角への倍率として適用。nil で解除し、ローカル Avatar の権限と有効期間に従います。
- マテリアル：Figura 基本テクスチャと `_n` 法線／`_s` スペキュラを Iris へ関連付け。動的画像の所有権と既存 YSM PBR を維持し、Iris なしでは通常描画を継続。
- アニメーション：エラーに部品・時刻・チャンネル・軸を表示。既知の v5 構文エラーに移行ヒントを追加し、Lua/Molang の計算規則は維持。
- スクリプト：require/listFiles にパッケージ内の仮想パスを使用し、他環境の ZIP モジュール名に対する Windows ファイル名制約を解消。キャッシュ・相対インポート・実 IO 境界を維持。
- 例と検証状況は[移植計画](../NoFigura功能移植计划书-P1-P2.md#14-alpha11-作者使用说明)を参照。実際の shader／ゲーム画面と2クライアント検証は MANUAL/PENDING。

## 1.0.0-alpha.10

- ナビゲーション：常駐の左アイコン列と模組ロゴを導入。ホバーで内容の上にメニューを展開し、重複タブを削除。衣装棚、ライブラリ、権限、設定、ヘルプを表示し、管理画面はサーバー確認済み管理者だけに表示します。
- 配装：Avatar / Accessories の一覧と操作群を分離。装飾の公開操作を先頭に配置し、コンパクトの右側選択／取付タブで一覧｜プレビューとプレビュー｜骨格を切り替えます。重複した骨格ボタンは削除しました。
- モデル情報とお知らせはコンパクト専用の独立入口を維持し、左プレビュー／右情報の等幅二列に変更。お知らせは独立スクロールし、モデル操作画面の上部余白を削除しました。
- コレクション、所有モデル、お気に入り、公開一覧、投稿に縦型 Avatar / Parts タブを追加。アバターは形式フィルターを維持し、装飾は非表示かつ適用しません。重複する用途選択を削除し、単項目フォームと管理画面の既存フロー、配装投稿の独立入口を保持します。
- カードは共通80×98 GUI単位、カバーは80×80正方形。カード群全体は水平中央・上端揃えです。480×252の自動コンパクト表示はフィルター開閉時とも3枚を表示し、ワイドは利用領域に応じた行列・ページ件数を維持します。状態アイコン、三点メニュー、クリック位置も同期します。
- サイズ・テクスチャ・スクリプト・接続の四状態を展開メニュー最下部へ移動。説明とエラー理由を保持し、折りたたみ時とプレビュー側では表示しません。
- 投稿カバーは正方形、ファイル選択欄は同じ高さ。通常編集・管理者編集ともカバーの変更・削除・プレビューからの範囲選択に対応します。
- 投稿進行はプレビュー上部に常駐するアップロード／検証／自動審査／完了の四点表示。未開始時は空の状態で、文字位置を統一し、ホバーで結果・エラーを表示。コンパクトは現在段階の文言だけを更新します。
- プレビュー選択で一覧・フィルター・スクロール・カバーを保持し、リクエスト間隔制御でRATE_LIMITEDの集中発生を抑制します。
- 承認済み装着者のモデル表示と非公開モデルの可視性設定を維持する対応バックエンドを提供。NeoForgeとTaCZ等の一人称腕描画で非可逆姿勢に起因するクラッシュを修正しました。
- バックエンドは実際の投稿検証・審査・結果を通知し、ポリシーや制限を変更しません。resource_kindで件数・ページ処理前に種類を絞り込むため、対応バックエンドの更新が必要です。GitHub Actionsはテストを実行せず、ビルド・パッケージ・成果物アップロードを維持します。
- バージョン範囲：8879d121を源とする既存Alpha.10基線は26.3、26.2、1.21.1、1.20.1へ移植済み。本輪の追加UI変更は26.1.2のみ実装・ビルドしています。26.3のナビゲーションクリック不応答は既知問題として保持します。
- 本輪UIはユーザーの受入確認済み。自動回帰とFabric/NeoForgeビルドは成功し、専用のマルチプレイ・Modパック受入はMANUAL/PENDINGです。

## 1.0.0-alpha.4.1

- 一人称：装飾コンポジションをカメラ相対の全身ポーズで毎フレーム一度再実行し（ジオメトリは破棄）、体に取り付けた装飾の RENDER/POST_RENDER、パーティクル、トレイルを動作させます。基礎と腕の part-to-world 行列を現在のフレームに更新します。
- シェーダー：カスタムパーティクルのパイプラインをブレンド別に Iris のパーティクルプログラムへ割り当て、Iris のシャドウパスではカスタムパーティクルのコールバック/抽出、グループ送信、装飾スクリプトの POST_RENDER 発火をスキップし、モデルビューからカメラ平行移動を除くことで、シェーダー使用時のトレイル/パーティクルの位置ずれを修正します。
- LambDynamicLights：パーティクル動的光源を公開 DynamicLightBehavior API でワールド光源として登録します。導入時は二重照明を避けるため内部ライトフィールドの注入を停止し、ワールド変更後に再登録します。未導入時は一度だけフォールバック警告を出し、内部ライトフィールドを継続します。
- パーティクル光源上限制御：`outfit.limits` の着用者あたり上限を超えた場合、先に有効化された N 個のみ点灯し、残りは生存したまま消灯します。`CustomParticle` に `setLightInterval(n)` / `getLightInterval()` と `light = { interval = n }` を追加し、光源化できるパーティクル n 個につき 1 個だけ動的光源にします（残りは表示を維持）。トレイル作成テンプレートに Light interval コントロールを追加しました。
- 装飾の調整/クリック後にトレイルやバニラパーティクルが固定位置に止まり、パーティクル動的光源が無効になる問題を修正（衣装棚を閉じた後にドラフトのワールドプレビューを保持しない、ワールド身体描画は常に RENDER、part-to-world 行列を毎フレーム更新、紙人形プレビューが描画モードを漏らさない）。
- Blockbench アーマチュアスキニング：armature/bone ノードを認識し、メッシュの静止変換をアーマチュア空間へベイクし、boneWorld × inverse(bindWorld) で変形します。読み込み後に追加されたスキニングデータとアーマチュア空間のボーン上書きに対応します。
- 標準アンカーのフォールバック：標準の Head/Body 名を持たないカスタム Figura/YSM リグでは、大文字小文字を無視した別名または最初のリグノードへフォールバックし、カスタムベースで Head 系装飾（hat など）が描画されない問題を修正します。
- 診断：一時的な publish/accessory draw/マウント欠落ログを削除。スクリプトエラーは引き続き報告します。
- ゲーム内のバージョン表示を「1.0 Alpha 3」から「1.0 Alpha 4.1」へ修正。
- 実クライアントのシェーダー、ミックスイン読み込み、画面検証は `MANUAL/PENDING` のままです。

- 編集インスタンスの削除/切り替え後も古いアンカードロップダウンが描画され、`OUTFIT_INSTANCE_MISSING` で衣装棚がクラッシュする問題を修正。共有スケルトンノードは最初のパスで重複排除し、一人称の手のキャプチャが `INVALID_OUTFIT_CONFIGURATION` で失敗しないようにしました。

- コントロール定義の一時的な 0..1 範囲により、`setRange` 前に保存済みスライダー値（interval、lifetime、frame_ticks、light_interval など）が 1 にクランプされる問題と、クラウド/外部状態の更新にスライダーが追従しない問題を修正。復元時の元値を保持し `setRange` 後に再正規化するとともに、外部で変更されたコントロール値へスライダーを同期します。

- Iris のシャドウパスでもエンティティの装飾スケルトンをキャプチャ/バインドしていたため、`SkeletonIndex.bindParts` がシャドウビューで `INVALID_OUTFIT_CONFIGURATION` を投げてクラッシュする問題を修正。シャドウパスでは装飾の送信をスキップし、メインビューの描画は維持します。

- 一部のモデル読み込み後、同じリソース ID のキャッシュ済みスケルトンが現在のネイティブ part グラフと一致せず、`SkeletonIndex.bindParts` が `INVALID_OUTFIT_CONFIGURATION` を投げる問題を修正。キャッシュバインド失敗時は現在のグラフを再キャプチャし、エンティティ描画をクラッシュさせません。

- ネットワーク設定の既定値を「許可」(`allow_networking=true`)、制限を「なし」(`networking_restriction=2`、NONE) に変更しました。

- マイコレクションのローカルソースに「ZIP としてエクスポート」を追加しました。アバターと装飾に対応し、既定では `omnimorph/export`（MISC の「エクスポート先」で変更可能）に `avatar_名前.zip` / `cosmetic_名前.zip` として保存します（`.ysm` は拡張子を維持し、重複時は `(2)` を付加）。元ディレクトリ構造を保持し、エクスポートはバックグラウンドで実行して結果を表示します。

- 仮想アンカーエディタに「確定」ボタンを追加し、現在の編集を適用してボーン階層へ戻れるようにしました。

- 仮想アンカーの作成/編集を改善しました。位置・回転フィールドがプレビュー内のアンカー座標軸マーカーをリアルタイム更新し、スケール欄を削除してアンカーのスケールを 1 に固定しました。「確定」でボーン階層へ戻れます。

- モデルライブラリの装飾プレビューで `cosmetic_controls` が nil になり、`newToggle` などのコントロール宣言が失敗する問題を修正。プレビューでも実際のコントロール API を利用できますが、値は保存されません。

- YSM/非 Figura ベースの一人称手描画で `prepareFiguraBase` を呼び、`INVALID_OUTFIT_CONFIGURATION` でクラッシュする問題を修正。装飾の手パスは Figura ベースのみに限定しました。

- 衣装棚プレビュー下部のステータスバー（サイズ・テクスチャ・スクリプト・バックエンド接続の 4 点）と読み込みエラー表示を復元し、`StatusWidget` / `LoadingErrorWidget` を再追加しました。

- ローカル衣装ベースの読み込みに失敗した場合、以前の GUI/ワールドプレビューを直ちに消去してエラーを表示し、前のモデルを残しません。成功した場合は従来どおり自動でワールドプレビューに入ります。

- 衣装棚を閉じた後も現在のローカル衣装のワールドプレビューを保持します（コミット・配信はしません）。再度開くかクリアした時にプレビュー生命周期で破棄されます。

- 衣装棚を開き直してローカル衣装のワールドプレビューを復元する際、サーバー確定済み衣装をクリーン基準にしつつローカル下書きの未保存状態を保持し、公開ボタンが誤って無効にならないようにしました。

- ローカル衣装のワールドプレビューは通常のワールド粒子/動的ライト経路を使用します。プレビューインスタンスは GUI の `PreviewParticleScope` をバインドしないため、ネイティブ粒子・tick・動的ライトがプレイヤーに追従します。

### 追加

- モデルとサムネイルを `cache/avatars` 直下に統一。モデルは `.oma`、画像は内容に対応した `.png` / `.jpg` で保存し、旧キャッシュを必要時に移行。鍵とアカウント情報は分離し、今後の装飾品には別ディレクトリを使用。
- コレクション情報は `.omc` を使用し、装飾品用に `.oms` と `cache/cosmetic` を予約。旧 `.omc` モデルはデータと鍵を維持して `.oma` に移行。
- 「コーデ / マイコレクション」の縦タブを追加。ローカル/クラウドの取得元とモデル/パーツのモードを独立させ、2.0 装飾機能は実装予定のレイアウトのみ表示。
- ライブラリを「ワードローブに追加」に変更し、自分の投稿もアカウントのクラウドコレクションへ自動追加。追加やプレビューでは装備を変更しません。
- コーデ候補、手動キャッシュ、権限に応じたクラウドモデル管理を追加。自動キャッシュは全体設定の「その他」に集約し、初期値は無効。
- 共通キャッシュを圧縮・暗号化した形式で保存し、直接展開による抽出を抑制。アカウントとモデルの権限確認は維持。
- Figura/YSM の読み取り専用ボーンツリーに初期折りたたみ、名前検索、展開状態の復元、横スクロールを追加。選択部分を枠で示し、他の部分を半透明化。
- 現在装備中のモデルの外観共有を、公開モデルでもライブラリの公開設定とは別に切り替え可能。

### 修正・改善

- 取得元と用途に初期値「すべて」を追加。ローカルとクラウドをまとめて表示し、コーデは候補のみを表示。「パーツ」を「装飾」に変更し、2.0 の案内を維持。
- プレビュー選択後に公開・非公開モデルの外観共有ボタンが無効になる問題を修正。装備状態を個別に追跡し、毎 tick の読み取り・保存のキャンセルを防止。

- コーデからの除外をローカル/クラウド項目の右クリックメニューへ移動。よく使う操作を先頭に置いて機能別に区切り、作成・フォルダー操作はコレクションのみ表示。ボーン更新は検索欄の隣へ移動し、項目を高くして左上の形式アイコンに統一。ライブラリのツールチップに形式名を追加。
- コーデ選択でプレビューが切り替わらない問題を修正。追加プレビューは Figura 本来のエンティティ GUI 描画を使用。
- カード、一覧とプレビューの比率、高さをライブラリに統一。取得元、モデル/パーツのモード、形式を「+」にまとめ、操作アイコンをプレビュー下へ移動。
- キャッシュ状態の中国語・英語訳を補い、翻訳キー検査の対象を拡張。
- 縦タブの文字欠落を修正。取得元・形式アイコンと1行の情報表示を統一し、重複する公開操作を整理。

クラウドコレクションからの削除と公開モデルの外観共有には対応するバックエンド更新が必要です。実ゲーム画面とマルチプレイの目視確認は `MANUAL/PENDING` です。
